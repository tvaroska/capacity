# `capacity` — Architecture & Product Roadmap (`v0.2.0` -> `v0.3.0` Showcase)

`capacity` unifies **empirical telemetry sizing**, **sub-second token-bucket & model-tier prefix-cache physics**, **multi-gateway configuration generation (`LiteLLM`, `Envoy AI Gateway`, `GKE Inference Gateway epp`)**, **Newsvendor hybrid commitment optimization**, **3-Tier Residual Capacity Scheduling**, and **FinOps FOCUS 1.2 Two-Pool Chargeback** across both **Managed Reserved Throughput (`GSU`)** and **Self-Hosted Open-Weight Models (`GPU / TPU Replicas`)**.

---
